## 3. F1 处置（验收方裁定，2026-10-28）

执行报告记 F1"无合格证据"，系执行方无法访问服务商账户所致。用户（账户持有人）2026-10-28 向验收方说明：其模型服务账户为**预付费、充值金额有限、余额耗尽自动停机**。验收方据此裁定：

- 边界：若日后开通自动充值、或长期在账户内放大额余额存放，本裁定须重估。

## 4. 与 spec 的偏差（接受，不挡开跑）

1. **sandbox 镜像降级**：默认 desktop 镜像拉取停滞，改用 digest 固定的 `python:3.12-slim`——容器内无桌面/Chromium/Node 能力，属能力取舍，已知且接受。
2. **容器磁盘配额未内核强制**：`container_disk` 已配置，因存储驱动不支持 XFS pquota 而未形成强制配额；CPU/内存配额实测生效，磁盘面以根盘余量与监视对冲。
3. **宿主域名级出口白名单未建**：工具容器完全断网、模型调用走固定 base URL，部分对冲；宿主进程出口未做域名级限制，记为已知敞口。
4. **上游遗留**：npm 锁文件高危/中危项待上游修复版；`custom_providers` 结构迁移、`session_reset` 插件取舍、Gemini 凭据连通性 400——均非当前主/fallback 路由，列入后续轮次，不挂本次验收。
