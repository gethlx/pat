# 窄案例监控清单与定时计划

> 沉淀日期：2026-10-11。配套文档：《01-体系蓝图与分析模型》。本清单是每周监测的关注对象与触发标准，随调研更新。

## 一、定时计划（已运行）

- **任务**：人类数据主权赛道每周监测（`weekly-data-sovereignty-watch`），每周三约 09:46（Asia/Shanghai）自动执行，结果推送到本侧聊；**有实质动向才推，无事不打扰**。
- **监测范围**：确权（A 人端确权 / B 内容指纹溯源）、定价（E 定价机制）、交易（C 数据交易市场）、D 嵌入式确权基础设施、F Agent skill 市场。
- **基线与去重**：`~/workspace/data-sovereignty-watch/baseline.md`（赛道盘点基线）、`seen.md`（已调研/已推送记录）。已存在项目的「存在本身」不算新闻，只报状态变化。
- **月度复盘**：每月第一周的那次运行，附《03-参与计划》的复盘提示（详见参与计划）。

## 二、窄案例清单（按层）

### Skill 市场（最窄、最可测的模式生物，重点盯）

| 案例 | 层位 | 关注理由 | 关键观察指标 |
|---|---|---|---|
| **EvoMap** | 三层全占（确权最强） | 唯一以 agent 为原住民、三层都认真做的系统 | Credit 能否出平台、成交量是否公开、付费资产定价方式、融资 |
| **Agensi** | 交易＋定价（法币） | 形态最像正经 skill 商店，Stripe 真结算 | 成交真实性的独立证据、规模口径 |
| **扣子 Coze 技能商店** | 交易（大厂节点） | 国内唯一付费＋收款跑通 | 分成比例/GMV 是否公开、是否开放确权 |
| **Vercel skills.sh** | 分发注册表 | 已赢免费分发轨道（7 个月 100 万 skill、约 2.8 亿安装） | **何时开收费/分成**——全场最大单一信号 |
| **GPT Store** | 准市场（收缩中） | 流量最大的前车之鉴 | 货币化政策变化 |
| **PromptBase** | 交易（长寿样本） | 付费数据资产市场存活最久（2022 至今） | 费率与订阅制变化、天花板验证 |
| **Virtuals ACP** | 结算（劳务非 skill） | 链上结算完成度最高，但已退潮 | 量是否回升、是否转向 skill 资产 |
| **VeriForge / x402 系** | 协议派样本 | Proof-of-Skill 收据＋按次付费，机制设计最完整 | x402 全网支付量、采用方 |

### 确权层

| 案例 | 关注理由 | 观察指标 |
|---|---|---|
| **World (WLD)** | 唯一规模化人端确权 | 验证增长是否恢复、各国监管进展、代币集中度 |
| **C2PA 生态** | 事实标准、设备预装进行中 | 新增预装设备/平台、法规引用 |
| **Truepic** | 无币但真出货（保险场景） | 企业客户与融资 |
| **Billions（原 Privado ID 团队）** | 转向「人类＋AI agent 双身份」 | agent 身份产品进展 |
| **Humanity Protocol** | 融资最高的 PoP 挑战者 | 安全事件后恢复情况 |

### 定价 / 评估层

| 案例 | 关注理由 | 观察指标 |
|---|---|---|
| **Scale AI / Surge / Mercor**（Web2 参照系） | 定价层以服务形态的现金流证明 | 估值/融资、向「数据定价」产品化延伸的动作 |
| **Sahara AI / Sapien / PublicAI** | 链上标注/评估小市值标的 | 真实客户与收入证据、解锁节奏 |

### 交易 / 数据 union

| 案例 | 关注理由 | 观察指标 |
|---|---|---|
| **Grass** | 自带流量节点原型＋宣称营收，全场基本面最强 | 营收的独立验证、新业务线（向数据交易延伸？） |
| **Vana** | DataDAO 路线与论点最贴 | 解锁抛压、DataDAO 实际交易 |
| **Ocean / DATA(Story) 等老所** | 尸体与转型样本 | 只报重大状态变化（退市、转型、死亡确认） |

## 三、触发信号（任一出现 → 推送时同步触发参与计划复盘）

1. EvoMap Credit 可出平台 / 公开成交量 / 融资；
2. 主流注册表（skills.sh 等）开收费或分成；
3. 大节点接入外部确权/定价协议（第二幕信号）；
4. x402 类 agent 支付量级跃升；
5. 「fork 后归因＋自动分账」被跑通且有规模。
