本区归共享记忆线维护，内容由该线按根目录 `AGENTS.md` 的规范自行同步入仓。本文件是立区说明与同步指引；除本说明外，本区文件均由共享记忆线写入，整体线不代写、不改动（规则见 `AGENTS.md`「写入规则」）。

## 本线是什么

为多个 Agent（多厂商 + 自定制）建设可共享的记忆层：经验记忆与知识层共存，记忆在各 Agent 之间可携带、可互通。本线节奏独立于 PAT 整体线——先行跑起来，未来与整体线在 `../contracts/` 的契约层对接。
