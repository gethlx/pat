## 本线是什么

为多个 Agent（多厂商 + 自定制）建设可共享的记忆层：经验记忆与知识层共存，记忆在各 Agent 之间可携带、可互通。本线节奏独立于 PAT 整体线——先行跑起来，未来与整体线在 `../contracts/` 的契约层对接。

## 预定收录（由共享记忆线同步时落位）

- 需求基准（已冻结版）与后续修订记录
- 选型调研与扫荡报告（候选评估、社区实证）
- 底座接入与验收记录（如验收门/冒烟结果）
- 胶水组件设计：多来源历史导入（ETL）、经验→知识晋升通道、统一 provenance 信封（与 `../contracts/` 对齐）
- 知识层（LLM Wiki）的说明与入口指针（Wiki 本体在独立仓 `gethlx/llm-wiki` 维护，不迁入本区）
