> 最后更新：2026-11-08
> 摘要：PAT 跨厂商 Agent 治理与共享记忆的工作仓，提供已冻结的 v2 蓝图、节点裁定与评审材料入口。

## 这是什么

PAT 现阶段的目标是用自有协调面统一派活、记账和共享记忆。多模态采集与数据主权是长期方向，硬件与采集设计见 v1 参考蓝图。

Meta 用 Confidential VM / Private processing 把用户自己采集的数据锁进黑盒——用户看不到、拿不到、导不出，而模型侧持续受益。这个项目是反方向的答案：**采集终端的所有权，就是数据的铸币权**。

目标不是"玩 gadget"，是**视频/多模态数据主权**：第一视角视频、语音、图像数据的采集、存储、定价、授权，全在自己手里。

多智能体共享记忆是本项目的子项目，按独立节奏推进，框架要求见 v2 §十一。分区维护规则见 `AGENTS.md`。

## 硬件与采集阶段参考

**两头开放，中间自主**——Agent 层可换、显示层可换；采集层、数据层、协议是自己的。

```
┌─────────────────────────────────────────────────┐
│ Tier 1 随身终端（固定）   输入+采集+瞥一眼        │  ← 贴身
│ Tier 2 大屏（开放渲染目标） 显示，可借屏          │  ← 随手
├─────────────────────────────────────────────────┤
│ Agent 层（可替换）            理解·任务·策略下发  │
├─────────────────────────────────────────────────┤
│ 数据层（自己的）   存储·定价·授权，开放格式       │
├─────────────────────────────────────────────────┤
│ 边缘层（可选）     缓冲·预处理·data mule          │
├─────────────────────────────────────────────────┤
│ 采集层（贴身，固定）  眼睛·耳朵·手                │
└─────────────────────────────────────────────────┘
```

## 设计原则

1. 数据走**开放格式、开放协议**（标准视频容器、结构化 JSON；MQTT / HTTP / 文件），不依赖任何厂商私有协议。
2. **触发判断下沉端侧**（L0 手动 → L1 定时 → L2 事件 → L3 端侧智能 → L4 Agent 协同；L2 做召回、L3 做精确，级联），云端只做策略下发和事后分析。
3. 私有协议**终止于你的固件**——单一 Agent 的相关代码只活在 adapter 里，不渗进数据层；换 adapter 时采集/数据/输出层不动。
4. 不把任何当前模型能力当永久约束；接口稳定，设备可升级。
5. 宁可少，不可脏——数据质量优先于数据量。
