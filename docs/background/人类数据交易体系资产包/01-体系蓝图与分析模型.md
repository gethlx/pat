# 人类真实数据交易体系蓝图与分析模型

> 沉淀日期：2026-10-11。来源：用户与老邪当日系列讨论。本文档是后续分析一切数据赛道项目的统一标尺（分析模型），随认知迭代修订。

## 0. 核心论点

AI 把「生成」打成免费品之后，真实、由人创造的数据成为稀缺品与硬通货。但数据的价值不会自动实现——必须有三层闭环：**确权 → 定价 → 交易**。缺任一层，价值无法被证明、无法流通、无法回流给数据生产者。当前生态的现状是：平台（Reddit 等）在替用户把人类数据卖出价，价值未回流本人。

## 1. 数据分类（三型，决定货币化姿势）

| 类型 | 例子 | 价值特征 | 货币化逻辑 | 确权方式 |
|---|---|---|---|---|
| ① 高价值 deliberate 数据 | 代码、文章、研究、专业标注、偏好反馈 | 单件价值高、可署名 | 艺术品逻辑：单件定价/拍卖/授权 | 创作端签名、版权框架 |
| ② 被动行为数据 | 点击、位置、驾驶、浏览轨迹 | 单条≈0、聚合是矿、单人无法归因 | 石油逻辑：data union 打包、论桶卖 | 身份绑定＋行为账本 |
| ③ 碎片化 exhaust 数据 | 照片、语音、聊天、传感器边角料 | 单条垃圾、聚合有价 | 聚合出售 | 设备端签名（硬件即人味来源） |

硬通货的三个准入条件：**可验证、够稀缺、有人买单**。分类轴不是「有没有创作价值」（文艺标准），而是可验证性、可聚合性、需求方是谁（经济标准）。

## 2. 三层体系

### 2.1 确权层

- **职责**：证明「谁、在何时、用什么设备/身份创造了这份数据」，并形成不可篡改的记账与血统（lineage）记录。
- **关键设计**：
  - 确权发生在创作的那一秒，由创作工具/设备顺手完成（C2PA 硬件签名、内容寻址 SHA-256、DID、可携带身份、审计事件链）。
  - **确权是功能，不是产品**：独立确权 App 必死；正确形态是分布式的插件/SDK/植入代码，跟随用户行为无感知全量记账埋点。
  - 账本归属是生死线：账本在单一厂商手里 = 新平台；必须在用户侧/分布式，链上只锚定哈希（全量上链成本不可行，本地哈希链＋定期锚定）。
- **结构性边界**：确权只证明「谁签的名」，不证明「内容是否原创」——**洗稿无解**：任何内容指纹都活不过足够强的改写。洗稿只能靠源头确权＋事后经济/法律追责，不能靠内容鉴伪。对策重心因此从「数据是什么」前移到「谁创造的」。
- **现状**：靠「恐惧」驱动（欺诈、合规、责任）已在跑：各国 AI 内容标识法规、保险核保（Truepic）、相机/Pixel 预装 C2PA。不需要数据市场先存在。

### 2.2 定价层

- **职责**：给出具备公信力的价格，使价值可被证明、交易可结算。
- **公信力原理**：定价的可信度不来自算法公正，来自**定价者要押注**。世界上只有两种可信价：(a) 真实成交跑出来的价；(b) 定价者质押真金白银、估错被罚没的价。不下注的估值只是意见，不是价格。
- **数据定价三难**：
  1. **Arrow 信息悖论**：不看不知道价值，看了就不用买。
  2. **非同质**：无标准单位、无统一品质分级，不像石油有品位标准。
  3. **情境依赖**：同一数据对不同买家（模型、已有数据组合）价值天差地别。
- **Arrow 悖论的三解（均为机器原生）**：
  1. 数据不动、模型过去（compute-to-data / TEE 沙箱）：买家买的是在数据上算出的结果，原始数据不出沙箱；同时治卖家的转卖恐惧。残余风险：权重记忆数据（成员推断），用差分隐私压量级。
  2. 看证明、不看内容：卖家先对全集哈希承诺，ZK 证明抽检样本确属全集、统计量属实——定价对象变成「承诺＋统计量＋保证」。人类买家要看货，agent 买家只需验证，这是根本不对称。
  3. 不事前定价、事后按实测结算：托管＋在买家验证集上测性能增量＋按约定公式自动释放付款。价格从「谈出来」变「测出来」。
- **与确权层的接口条件**：确权账本必须**公开可读**，否则定价方拿不到原始记账，分工就是假的（控制权只是换地方藏）。Chainlink 能独立于交易所，前提即链上数据人人可读。
- **现状**：开放定价不存在；定价以「服务」形态在实验室内部运行——标注/eval 行业（Scale AI、Surge、Mercor）就是定价层的胚胎：按条/按增量收钱，已有真实现金流。

### 2.3 交易层

- **职责**：撮合、清算、分成——价值回流的最后一环。
- **为何无法独自成立**：没货（确权缺位）、没价（定价缺位）、没信用，交易所是空房子。历史上所有纯数据交易所均死于此。
- **中心化节点生存三件套**（交易层破局的唯一已知路径：先成为中心化节点独自证明可生存，再连接其他两层）：
  1. **品牌代确权**：节点验货、赔付，信任来自品牌而非协议；
  2. **自营定价台代定价**：节点自己估价、甚至自己吃库存当经销商赚价差；
  3. **流量业务代流动性**：节点必须先有一门高频业务带来源源不断的人（标注平台的工人与实验室、Grass 的带宽用户）——交易是流量业务的第二曲线，不是独立物种。
- **第二幕难题**：节点做大后，其护城河恰是「信任与定价都在我这」，连接开放协议 = 自毁护城河，理性节点拒绝连接（Reddit 结局：交易跑通、价值全归平台）。
- **逼节点连接的三外力**（按看好顺序）：① **agent 买家**——agent 不认品牌、只认机器可验证接口，买方换物种是最强外力；② 供给侧觉醒——生产者要求可携带/可迁移；③ 监管强制互操作（DMA 式可携带立法），最慢最硬。

## 3. 分工 vs 一体化（组织原则）

- **终局必须分工**：同一主体左手确权、右手定价是结构性作弊位（可伪造记账、虚增用量、自报高价），公信力不可能成立；且与「确权层中立基础设施」的前提自相矛盾。
- **一体化只可作冷启动**：一家主体可先孵化确权＋定价跑通（彭博模式），但必须把定价层做成开放竞争市场（谁都能来当定价者、押质押金），否则永远只是自营商店。
- **定价层形态**：不是一家「官方定价机构」，而是开放市场：多个定价者/策展人竞争，估对赚钱、估错罚没。
- 闭环正确形状：**中立确权协议（公共品）→ 开放定价市场（竞争＋质押）→ 交易清算**。

## 4. Agent 经济扩展

- **主体替换**：未来交易者可能是高自主性 agent。押注的「钱」未必是法币或代币，可能是 agent 可支配的**算力 token**。
- **算力押注为何更硬**：算力是 agent 的生存资源（押算力被罚没 = 扣运行时长，是押命不是押钱）；且算力有真实物理成本、不可伪造。
- **成立三条件**：① 算力 token 外生稀缺（锚定真实硬件产能、网络发行，不能自印）；② agent 身份不可随意分叉（否则分身当炮灰、弃号重开——agent 的身份＋声誉记账成为定价的前置层）；③ 结算机器可验证（无法院兜底，争议必须能被客观指标裁决）。
- **价值的客观锚**：对 AI 买家，数据价值 ≈ 替代成本——「不用这份数据、靠多烧算力达到同样效果要花多少」。人类市场卡了几十年的「价值太主观」，在机器买家处部分消失：价格 = 性能增量 ÷ 算力成本，全程可测可结算。
- **推论**：闭环可能先在机器对机器的市场跑通，人类市场再蹭其基础设施（与直觉相反的顺序）。「硬通货」名单随之扩展：**数据之外，算力（押金与计价锚）＋身份记账（agent 信用底座）同为硬资产**。

## 5. 突破顺序（中短期预测）

1. **确权层先行**——恐惧驱动（欺诈/合规/责任），不依赖其他层；入口是创作设备与工具。**已破，但价值暂未轮到散户。**
2. **定价层次之**——实验室内部刚需，先以服务（标注/eval）形态收钱，评估方法与基准沉淀为行业共识后，开放定价才有米下锅。**进行中。**
3. **交易层最后**——无外生需求；先在某个 agent 生态的围墙花园内三层一体闭环（自有 agent＋自有算力计价＋自有记账，如早期银行卡先在一家银行体系内跑），再跨生态互联。**未破，信号未至前不抢跑。**

## 6. 分析标尺（评估任何项目逐项过）

1. 它在哪一层？三层各完成几成？
2. 有当下现金流吗？靠什么活着（真实收入/融资/代币投机）？
3. 有自带流量入口吗？交易是否长在某个高频业务上？
4. 确权：账本归谁？归因在 fork/转手/洗稿后是否存活？
5. 定价：谁定价？定价者押注了吗？价格可验证、可结算吗？
6. 交易：Credit/代币有价值出口（可提现/可跨平台）吗？成交量公开可验证吗？
7. 它是节点还是协议？处于第一幕（独自成立）还是第二幕（协议连接）？
8. 数据口径：项目方自报的用户数/营收/合作，一律先打问号，要求独立来源。

## 7. 信号清单（与每周监测对齐，任一出现即升级关注）

1. EvoMap 的 Credit 变为可提现/可对外交易，或官方公开真实成交量；
2. 任一主流 skill 注册表（skills.sh、MCP registry 等）开启收费或创作者分成；
3. 任一较大节点宣布接入外部确权协议或外部定价协议（第二幕开场铃）；
4. x402 等 agent 按次支付协议的交易量量级跃升；
5. 有项目跑通「fork 后归因存活＋自动分账」并出现实际规模。
